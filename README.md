# Firm Foundations Fitness

A static website for a faith-driven fitness community.

## Free hosting with GitHub Pages

1. Create a new **public** GitHub repository named `firm-foundations-fitness`.
2. Upload `index.html`, `styles.css`, `script.js`, this `README.md`, and the `.github` folder.
3. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
4. Push to the `main` branch. The workflow will publish the site automatically.
5. After the workflow finishes, GitHub will show the live URL under **Settings → Pages**.

The site is plain HTML, CSS, and JavaScript, so no build server or paid service is required. Every future push to `main` republishes it.
